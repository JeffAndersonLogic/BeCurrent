# Red Accent Pass

This prototype pass restores the original BeCurrent logo without grayscale filtering and reintroduces the original Press Red (#B03A2E) as a restrained accent over the carbon / gunmetal / warm-paper base.

Red is limited to high-information moments: current navigation, Current Wire label, primary calls to action, the TODAY node in Reverse History, active controls, primary-source markers, progress, and teacher notes. Silver remains the supporting neutral system rather than the brand accent.
