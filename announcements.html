Everything on this board is generated. Edit assets/data/announcements-schedule.js, then run node scripts/build-announcements.js. The targets and criteria come out of the course data, so the board cannot say something the lesson does not. The board rebuilds itself when the date rolls over, so it can stay up overnight.
