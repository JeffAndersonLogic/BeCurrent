# The dark Desk and TODAY board stylesheets, retired 2026-10-20

These styled the carbon-and-press-red versions of the Desk (`daily/`) and the
TODAY board (`announcements.html`). On 2026-10-20 both surfaces, and the front
door, moved to the light Midterms design system with the new logo:
`assets/css/desk-clean.css` and a rewritten `assets/css/becurrent-announcements.css`
replace them. `desk-2-patch.css` was already unlinked before that date. Kept here
so the old look can be recovered, not used.
