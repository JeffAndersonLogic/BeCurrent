# The C mark, retired 2026-10-20

`becurrent-mark-source.svg` is the vector artwork for the earlier BeCurrent mark:
"Be", an oversized red C, then "URRENT". It was the source the brand folder was
derived from until 2026-10-20, when the teacher supplied a new logo (the heavy
"BeCurrent." word with a red full stop). The new artwork lives in
`assets/images/brand/source/` and `scripts/brand/build-wordmark.py` now traces
that instead. Kept here so the old mark can be recovered, not used.
